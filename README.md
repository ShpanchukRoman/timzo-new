# timzo

Планувальник робочих змін з українським інтерфейсом, адаптивними таблицями та встановленням як PWA на iPhone й Android.

## Розробка

Встановіть залежності командою `npm install`, потім запустіть `netlify dev --port 8889`. Сервер відкриває застосунок за адресою `http://localhost:8889` та маршрутизує API до Netlify Functions.

Авторизацію реалізовано через Netlify Identity. Повні сценарії реєстрації, підтвердження email, відновлення пароля та входу потрібно перевіряти на розгорнутому сайті: Identity не емулюється локально. Підтримуються підтвердження email, запрошення, відновлення пароля та налаштовані в Identity зовнішні провайдери.

Дані зберігаються в Netlify Database. Схему визначено в `db/schema.ts`, міграції — у `netlify/database/migrations`. Після зміни схеми створіть міграцію командою `npx drizzle-kit generate --name add_employee_field`, використовуючи назву латиницею. Платформа застосовує міграції під час розгортання; вручну виконувати їх не потрібно.

Перевірки: `npm test` та `npx tsc --noEmit --incremental false`.

## Перехід із попереднього сервера

Залежність від Supabase вилучено з застосунку. Кожен новий обліковий запис Identity отримує окремий робочий простір. Старі облікові записи, графіки та посилання не імпортувалися автоматично: попередній сервер був недоступний. SQL у `supabase/` залишено як опис попередньої структури для подальшого перенесення з експорту.

## Встановлення на iPhone

Відкрийте сайт у Safari, виберіть «Поширити» → «На початковий екран» → «Додати». Встановлений вебзастосунок відкривається в окремому вікні. Це PWA, а не окремий застосунок App Store. Для завантаження та збереження графіків потрібен інтернет; приватні сторінки та відповіді API не кешуються для офлайн-доступу.
